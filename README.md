# Intro component with sign up form

![Design preview for the Intro component with sign up form challenge](./design/desktop-preview.jpg)

Solution to the Frontend Mentor **Intro component with sign up form** challenge - a responsive form built from the provided design.

**Live demo:** https://erfan-revenant.github.io/Intro-component-with-sign-up-form/

## Built with

- Semantic HTML5
- CSS custom properties, Flexbox and media queries
- Vanilla JavaScript for the interactive behaviour (no framework, no build step)
- Bundled webfonts and SVG assets from the challenge starter files

## Run locally

```bash
git clone https://github.com/ErfanBagheri404/Intro-component-with-sign-up-form.git
cd Intro-component-with-sign-up-form
```

Open `index.html` in a browser. Nothing to install or compile.
